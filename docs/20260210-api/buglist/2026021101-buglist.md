# API开发规范整改方案

## 违规问题汇总

根据全面审查，发现代码中存在多项严重违反开发规范的问题：

### 1. 严重违规：多个类/函数在同一文件中

**违规文件列表：**
- `src/llama/config/config.py` - 包含5个类
- `src/llama/core/security.py` - 包含2个类
- `src/llama/exceptions/__init__.py` - 包含6个类

**规范要求：** 每个类和函数必须单独一个 .py 文件，绝对不允许在一个 .py 文件中出现两个或两个以上的类或函数

### 2. 严重违规：代码中包含大量注释

**规范要求：** 代码中不允许添加注释

### 3. 违规：行长度超过79字符

**规范要求：** 每行最大长度 79 字符

### 4. 违规：布尔值比较不显式

**规范要求：** 布尔值比较应显式 (e.g., `if flag is True:` 而非 `if flag:`)

## 详细整改方案

### 第一步：分离多类文件

#### 1.1 分离 `src/llama/config/config.py`

创建以下新文件：
- `src/llama/config/model_config.py` - 移动 `ModelConfig` 类
- `src/llama/config/resources_config.py` - 移动 `ResourcesConfig` 类
- `src/llama/config/security_config.py` - 移动 `SecurityConfig` 类
- `src/llama/config/service_config.py` - 移动 `ServiceConfig` 类
- 修改 `src/llama/config/config.py` - 仅保留 `Config` 类

#### 1.2 分离 `src/llama/core/security.py`

创建以下新文件：
- `src/llama/core/rate_limiter.py` - 移动 `RateLimiter` 类
- 修改 `src/llama/core/security.py` - 仅保留 `ConcurrencyController` 类

#### 1.3 分离 `src/llama/exceptions/__init__.py`

创建以下新文件：
- `src/llama/exceptions/api_error.py` - 移动 `APIError` 类
- `src/llama/exceptions/validation_error.py` - 移动 `ValidationError` 类
- `src/llama/exceptions/rate_limit_error.py` - 移动 `RateLimitError` 类
- `src/llama/exceptions/service_error.py` - 移动 `ServiceError` 类
- `src/llama/exceptions/model_load_error.py` - 移动 `ModelLoadError` 类
- `src/llama/exceptions/authentication_error.py` - 移动 `AuthenticationError` 类
- 修改 `src/llama/exceptions/__init__.py` - 仅导出各异常类

### 第二步：删除所有注释

#### 2.1 删除代码行内的注释
- 移除所有 `#` 开头的注释
- 移除行末的注释（如 `# 禁止额外字段`）

#### 2.2 保留必要的文档字符串
- 保留符合 PEP 257 规范的模块、类和函数文档字符串
- 删除文档字符串中的注释性内容

### 第三步：修复行长度问题

#### 3.1 修复长导入语句
将长导入语句分行：
```python
# 修改前
from src.llama.core.security import verify_api_key, get_rate_limiter, get_concurrency_controller

# 修改后
from src.llama.core.security import (
    verify_api_key,
    get_rate_limiter,
    get_concurrency_controller
)
```

#### 3.2 修复其他长行
- 将超过79字符的长行适当分行
- 遵循 Python 的隐式行连接规则

### 第四步：修复布尔值比较

#### 4.1 显式布尔比较
将所有隐式布尔比较改为显式比较：
- `if flag:` → `if flag is True:`
- `if not flag:` → `if flag is False:`
- `if value:` → `if value is not None:` (针对可为空的值)

### 第五步：更新导入语句

#### 5.1 按规范分组导入语句
- 标准库导入
- 第三方库导入
- 本地库导入

各组之间用空行分隔。

#### 5.2 更新所有受影响的导入路径
修改所有因文件拆分而受影响的导入语句。
