## 项目概述

osins-llama 是一个基于 llama-cpp-python 的生产级推理 API 服务，兼容 OpenAI Chat/Completion 接口风格。项目旨在提供高并发、可观测、安全、可测试、可扩展的系统架构。

## 技术栈

- **框架**: FastAPI
- **推理引擎**: llama-cpp-python
- **数据验证**: Pydantic v2
- **服务器**: Uvicorn + Gunicorn
- **容器化**: Docker + Docker Compose
- **测试**: pytest + httpx
- **依赖管理**: Poetry
